Overview

The Cell Line Analysis of Mutation Pipelines (CLAMP) is a harmonized somatic mutation resource for tumor cell-line models. CLAMP reprocessed raw sequencing data and recalled exome-wide single-nucleotide variants (SNVs) and short insertions and deletions (indels) across 1,269 cell lines using four contemporary mutation callers: DeepSomatic, Lancet2, Mutect2, and Strelka2.

CLAMP was developed to improve the consistency and interpretability of mutation profiles across major cancer cell-line resources. Because published cell-line mutation profiles were generated using different sequencing centers, preprocessing strategies, and variant-calling pipelines, the same cell line may have discordant mutation calls across resources. CLAMP addresses this by applying a harmonized processing workflow and making both caller-specific and integrated mutation callsets available for comparison.

The primary CLAMP callset is Union(D,L), the union of mutations called by DeepSomatic or Lancet2. This callset was selected based on benchmark performance against ultra-high-depth reference datasets and is intended as the default high-confidence mutation set for most analyses. Individual caller outputs are also provided for users interested in caller-specific behavior, sensitivity-focused analyses, or method comparison. Absence of a mutation from Union(D,L) should not be interpreted as definitive absence from the cell line, particularly in regions with limited coverage or caller disagreement. Users should also note that independently propagated versions of the same cell line may differ because of genomic drift or culture-specific evolution.

CLAMP currently focuses on SNVs and short indels. Copy-number alterations, structural variants, gene fusions, and expression-level changes are outside the primary scope of this release unless otherwise indicated.

Data Sources

CLAMP integrates sequencing data from major tumor cell-line resources, including the Cancer Cell Line Encyclopedia (CCLE) and the Cell Models Passport (CMP). These resources contain overlapping but not identical cell-line collections, and some cell lines were independently profiled by more than one sequencing center. For each cell line, CLAMP records the source resource, sequencing provenance, assay type, and profile identifier associated with the analyzed data.

Because the same nominal cell line may have multiple available sequencing profiles, CLAMP distinguishes between the cell-line model and the specific sequencing profile used for mutation calling. Multiple profiles may reflect independent sequencing by Broad/CCLE and Sanger/CMP, different assay types such as WES and WGS, or replicate profiling within a resource. Users should account for this provenance when comparing mutation calls across resources or interpreting discordance between profiles.

Cell-line identifiers were harmonized across resources using shared model identifiers where available, with primary names, aliases, resource-specific IDs, and lineage annotations retained for search and filtering. When displaying originally published or DepMap-derived comparator mutation profiles, CLAMP retains source-matched mutation data: Broad-derived comparator calls are matched to Broad-derived CLAMP sequencing profiles, and Sanger-derived comparator calls are matched to Sanger-derived CLAMP sequencing profiles. This avoids comparing mutation profiles generated from different sequencing runs of the same nominal cell line.

Not every cell line has data from every source or assay type; users should consult the profile-level metadata to determine which sequencing source, assay type, and comparator data are available for a given cell line.

Mutation callsets

CLAMP provides mutation calls generated by four individual callers—DeepSomatic, Lancet2, Mutect2, and Strelka2—as well as integrated callsets derived from combinations of these callers. The primary CLAMP callset is Union(D,L), defined as the union of mutations nominated by DeepSomatic or Lancet2.

Union(D,L) was selected as the default high-confidence callset because it achieved the best precision–recall balance in benchmark comparisons against ultra-high-depth reference datasets. For most analyses that prioritize reliable SNV/indel mutation labels, Union(D,L) is the recommended starting point. Individual caller outputs are also retained so users can inspect caller support, evaluate caller-specific behavior, or perform analyses that prioritize sensitivity over the default high-confidence callset.

For each mutation, CLAMP reports whether the variant was nominated by DeepSomatic, Lancet2, Mutect2, and/or Strelka2, along with whether it is included in Union(D,L). Caller support can help users distinguish variants supported by multiple algorithms from variants detected by a single method, but should be interpreted in the context of sequencing source, assay type, coverage, and the intended analysis.

CLAMP also includes originally published mutation callsets where available, allowing users to compare harmonized CLAMP calls with previous resource annotations. In cross-resource comparisons, these original callsets may correspond to the respective published mutation profiles from each source resource.

Absence of a mutation from Union(D,L) should not be interpreted as definitive absence from the cell line, particularly in regions with limited coverage or caller disagreement. Disagreement among callers does not necessarily imply that a mutation is false; it may reflect local sequence context, read support, coverage, variant type, or caller-specific modeling choices.

Processing and filtering

CLAMP processes mutation data at the sequencing-profile level. Each profile is associated with a source resource, sequencing center, assay type, and source-specific sample identifier. When the same nominal cell line was profiled by multiple resources or assay types, those profiles were retained separately rather than collapsed into a single mutation set.

Sequencing data were processed through a harmonized workflow before mutation calling. This workflow used the hg38 reference genome and standardized preprocessing steps to generate comparable inputs across CCLE- and CMP-derived profiles. Somatic SNVs and short indels were then called using four mutation callers: DeepSomatic, Lancet2, Mutect2, and Strelka2.

Caller outputs were normalized to a common variant representation using chromosome, position, reference allele, and alternate allele. Calls from different mutation callers were merged when they referred to the same normalized variant in the same sequencing profile. CLAMP reports caller support for each mutation and defines Union(D,L) as the set of mutations nominated by DeepSomatic and/or Lancet2.

When comparing CLAMP calls with originally published or DepMap-derived mutation profiles, source-matched comparator records were retained. Broad-derived comparator calls were matched to Broad-derived CLAMP sequencing profiles, and Sanger-derived comparator calls were matched to Sanger-derived CLAMP sequencing profiles. This avoids comparing mutation profiles generated from different sequencing runs of the same nominal cell line.

The primary CLAMP views focus on somatic SNVs and short indels. Depending on the app view, users may filter mutations by gene, genomic coordinate, coding consequence, source profile, assay type, caller support, and inclusion in Union(D,L). Absence of a mutation from a filtered view may reflect filtering choices, caller disagreement, limited coverage, or profile-specific differences, and should not be interpreted without considering the underlying sequencing profile and callset.

Using the app

The CLAMP webapp embeds a cBioPortal deployment for interactive exploration of mutation profiles. Users can query genes and mutations, view mutation tables and OncoPrint-style summaries, inspect available sample metadata, and download selected results. CLAMP-specific metadata—including sequencing source, assay type, source resource, callset, and caller support—are provided as study annotations or custom data fields where available.

For most analyses, we recommend beginning with Union(D,L), the default high-confidence CLAMP callset, and then inspecting caller support and profile-level metadata to interpret individual mutations. When multiple sequencing profiles exist for the same nominal cell line, these profiles are represented separately so that source, assay, and sequencing-center provenance are preserved.

Some CLAMP-specific concepts, including source-matched comparator filtering, genomic drift caveats, and detailed processing decisions, are described in the accompanying documentation rather than enforced by cBioPortal itself.

Caveats

CLAMP provides harmonized, high-confidence SNV and short-indel calls, but it is not a complete truth set for every cell line. Union(D,L) is recommended as the default high-confidence callset, but absence from Union(D,L) should not be interpreted as definitive absence of a mutation.

Mutation calls are displayed at the sequencing-profile level. Multiple profiles for the same named cell line may differ because of sequencing source, assay type, sample handling, genomic drift, or culture-specific evolution.

CLAMP reduces technical discordance from preprocessing and mutation-calling differences, but it cannot fully separate technical artifacts from biological divergence. Originally published callsets are included for comparison and provenance.

CLAMP currently focuses on somatic SNVs and short indels. Drug-response data, where shown, are derived from cell-line screens and should not be interpreted as clinical treatment recommendations.

Analyses using CLAMP should report the release version, selected callset, sequencing source, assay type, and filters used.

Downloads and citations

CLAMP downloads include the selected Union(D,L) callset, individual caller outputs, profile-level metadata, and annotation tables used by the webapp. Where available, originally published comparator callsets and linked pharmacogenomic metadata are provided as separate files.

Users performing caller-specific or sensitivity-focused analyses may use the individual caller tables or caller-support fields in the merged mutation file.

CLAMP is versioned. When using CLAMP data, please report the release version, selected callset, genome build, sequencing source, assay type, filters applied, and date accessed. Please cite the CLAMP manuscript and any linked external data resources used in your analysis.

Questions or suspected data issues can be sent to daniel.halmos@dph.ox.ac.uk with the relevant release version, cell-line identifier, callset, and mutation or profile ID.
